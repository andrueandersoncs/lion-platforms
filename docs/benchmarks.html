We Benchmarked Claude Sonnet 5.5 Against
Claude Sonnet 5.5 + a Symbolic Engine

Full-corpus live A/B trials across 60 policy guardrail cases, 10 multi-source due-diligence packets (50 sources), and 15 multi-agent incident episodes — reporting both where a frontier model excels on its own and the structural gaps where symbolic verification delivers orders-of-magnitude gains.

Methodology

Fair, isolated, reproducible — zero strawman prompts

Experimental setup: Every live run executed claude -p --model sonnet (resolved to claude-sonnet-5-5) with --tools "" --strict-mcp-config --setting-sources "" --no-session-persistence --json-schema to eliminate workspace leakage. Both Control and Treatment arms used the exact same model and crystal-clear system prompts. Total combined API spend across all 3 full-corpus trials was ~$1.24.
